## 📌 Các chức năng và Route kiểm tra

1. **Trang chủ mặc định:**
   - URL: `https://localhost:7090/` hoặc `/Home/Index`
   - Điều khiển bởi: `HomeController`

2. **Trang Hello Index:**
   - URL: `https://localhost:7090/Hello` hoặc `/Hello/Index`
   - Hiển thị: Giao diện chào mừng từ View `Index.cshtml`.

3. **Trang Hello Welcome (Truyền tham số qua ViewData / ViewBag):**
   - URL mẫu: `https://localhost:7090/Hello/Welcome?name=Bang&numTimes=4`
   - Hiển thị: Lặp lại thông điệp chào mừng theo số lần `numTimes`.
